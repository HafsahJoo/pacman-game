
# **Pacman Game**

Pacman is a fun Python-based game built using the Pygame library. It offers a chomping adventure, featuring a main menu, a mini-game, user accounts, and customizable gameplay.

---

## **Prerequisites**

Before running the game, make sure you have the following installed:

1. **Python 3**  
   To install Python 3, run:  
   ```bash
   sudo apt-get install python3
   ```

2. **Pygame**  
   For game development and multimedia features:  
   ```bash
   pip install pygame
   ```

3. **OpenCV-Python**  
   For image and video processing tasks:  
   ```bash
   pip install opencv-python
   ```

4. **Passlib**  
   For secure password hashing and authentication:  
   ```bash
   pip install passlib
   ```

5. **Bcrypt**  
   For securely hashing passwords:  
   ```bash
   pip install bcrypt
   ```

6. **NumPy**  
   For handling numerical operations and arrays:  
   ```bash
   pip install numpy
   ```

7. **SQLite3**  
   SQLite is built into Python, but you may need the libraries:  
   ```bash
   sudo apt-get install sqlite3 libsqlite3-dev
   ```

---

## **How to Run**

1. Ensure that all prerequisites are installed.

2. Open a terminal and navigate to the program's directory:
   ```bash
   cd path/to/directory
   ```

3. Run the program using the following command:
   ```bash
   python3 pacman.py
   ```

4. Follow the on-screen prompts to start playing and customize your game.
